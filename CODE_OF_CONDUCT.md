# Code de conduite

Ce projet adopte le [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.

## Notre engagement

Nous nous engageons à faire de la participation un expérience sans harcèlement, quels que soient l'âge, le corps, le handicap visible ou invisible, l'ethnicité, les caractéristiques sexuelles, l'identité ou l'expression de genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité, l'apparence, la race, la caste, la couleur, la religion ou l'orientation sexuelle.

## Comportements attendus

- Empathie et respect.
- Critique constructive des idées, pas des personnes.
- Responsabilité en cas d'erreur.
- Intérêt collectif du projet (licence, sécurité, isolation des modules privés).

## Comportements inacceptables

- Langage ou image sexualisés, avances non consenties.
- Trolling, insultes, attaques personnelles ou politiques.
- Harcèlement public ou privé.
- Publication d'informations privées (adresses, secrets, données de facturation) sans permission.
- Toute conduite raisonnablement inappropriée en milieu professionnel.

## Application

Les mainteneurs Arowtech peuvent retirer commentaires, commits, code, issues et PR, et exclure temporairement ou définitivement un contributeur.

Signalement : canal privé du steward (advisory GitHub ou contact mainteneur). Les signalements sont traités confidentiellement.

Ce Code of Conduct s'applique dans tous les espaces du projet et lorsqu'une personne représente le projet.
